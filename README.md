# Studio Dorian — full GitHub Pages website

This version includes the full Pelagia archive drawn from the uploaded booklet.

## Upload to GitHub

1. Download and unzip this ZIP.
2. Open your GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - the entire `assets` folder
5. Commit the changes.
6. Open **Settings → Pages**.
7. Choose **Deploy from a branch**.
8. Select `main` and `/ (root)`.
9. Save.

## Custom domain

Once the GitHub Pages site is live, add `studiodorian.co.uk` under **Settings → Pages → Custom domain**.
